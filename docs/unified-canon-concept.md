# Retired domain SDK

Canon 0.17.0 removes the common HTTP/SSE/RPC domain SDK and its
HTTP generator. Use the [version-2 generation workflow](codegen.md) and follow
its [migration instructions](codegen.md#migration-from-version-1).

Shared Python error declarations and specialized transport clients remain.
See [the design rationale](sdk-design.md). Historical published behavior is
recorded in the changelog and matching release tags.
